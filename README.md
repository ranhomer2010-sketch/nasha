# АРС-42 — первая версия сайта

## Просмотр

Откройте `index.html` в браузере. Это самостоятельный HTML-файл: стили,
графика и JavaScript находятся внутри. Сборка и установка пакетов не нужны.

Четыре блока: предложение, команда, причины работы с нами, анкета.
Визуальное направление: голубой, светло-серый, розовый акцент; крупная типографика.
Видеофона пока нет. Вместо него используется локальная композиция из CSS.

## Видео

1. Положить готовый MP4 в `assets/path-of-a-lead.mp4`.
2. В `index.html`, в JSON внутри `script#site-config`, установить
   `videoDesktop` в `assets/path-of-a-lead.mp4`.
3. При наличии отдельного вертикального видео указать `videoMobile`.
   Если оно не указано, на телефоне используется адаптированный десктопный ролик.
4. Запустить `python3 tools/finalize.py` для обновления CSP после любых правок.

Время видео привязано к четырём смысловым разделам, по четверти ролика на раздел.
При прокрутке вверх видео перематывается назад. Автовоспроизведения со звуком нет.
Для `prefers-reduced-motion` видео не загружается при первоначальном открытии,
сохраняется статичный фон. При ошибке видео также остаётся статичная композиция.
Путь видео должен вести на тот же сервер; внешний адрес отклоняется.
Производительность перемотки будет проверена на фактическом файле после его получения.

## Анкета: сейчас только предпросмотр

Работают три шага, выбор задачи, проверка полей, ссылка на бизнес, ник Telegram,
выбор времени встречи, отдельное согласие и просмотр заполненной анкеты.
Данные остаются в DOM текущей страницы: нет API, fetch, отправки в Telegram,
cookies, localStorage, sessionStorage или экспорта данных. В URL поля не передаются.
После перезагрузки сайт не восстанавливает заполненную анкету.
Строки в итоговом просмотре вставляются через textContent.

Нет подключения Метрики, Вебмастера, внешних шрифтов, CDN, карт, AI API или виджетов.
Упоминание Метрики и Вебмастера в оффере описывает предлагаемую услугу.
Админка в оффере — часть услуги клиентам; отдельная админка этого сайта ещё не создавалась.

## Перед рабочим запуском

Это версия для согласования дизайна, не production с приёмом заявок.
Размещать рабочий сайт нужно на российском хостинге согласно переданному стандарту.
На зарубежный production-хостинг эта версия не опубликована.

Для включения сбора заявок потребуются:

- Реквизиты оператора и контакт для обращений по персональным данным.
- Утверждённые отдельные политика и согласие вместо текущих проектов в диалогах.
- Российский backend, БД, логи и резервные копии; выбор конкретной инфраструктуры.
- POST API с серверной проверкой полей, ограничением частоты, защитой от спама
  и фиксацией версии согласия и времени его предоставления.
- Сроки хранения, удаление данных, порядок отзыва согласия и организация доступа.
- Проверка уведомления Роскомнадзора и договоров обработки с подрядчиками.
- HTTPS и HTTP-заголовки из `security-headers.txt` на выбранном сервере.
- Проверка Network на финальном домене.

Форма намеренно не становится рабочей от изменения `preview` в конфигурации.
Требуется реальное подключение backend и юридических документов, после чего
будут точечно изменены CSP `connect-src` и `form-action`.

## Поисковики и ИИ

Контент находится в исходном HTML, доступен без JavaScript: один H1,
семантические разделы, списки услуг, язык ru, description и JSON-LD Service/Offer.
На этапе предпросмотра стоит `noindex, nofollow` и `robots.txt` закрыт.
Перед публичным запуском: подтвердить домен и бренд, добавить canonical,
финальные Open Graph URL/изображение и sitemap, открыть индексацию.
Читаемая структура помогает машинному разбору, но не гарантирует выдачу в ИИ.

## Изменения

После правок HTML запускать `python3 tools/finalize.py`. Скрипт обновляет
криптографические хеши inline CSS/JS в CSP и `security-headers.txt`,
проверяет отсутствие внешних ресурсов и базовую структуру.

Весь визуальный код написан для проекта. Внешних библиотек и растровых
изображений нет; используется системный шрифт устройства.
